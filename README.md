# API-тесты для учебного сервиса Яндекс.Самокат

Этот проект содержит автоматизированные API-тесты для проверки корректности работы сервиса «Яндекс.Самокат». Тесты написаны на **Python** с использованием **pytest**, **requests** и оформлены с использованием **Allure** для удобной отчетности.

## Описание тестов

Тесты проверяют следующие сценарии работы API:

### **Создание курьера**

- Проверяется, что курьера можно создать.
- Нельзя создать двух одинаковых курьеров.
- Для создания курьера необходимо передавать все обязательные поля.
- Запрос возвращает правильный HTTP-код ответа.
- Успешный запрос возвращает `{"ok": true}`.
- Если одного из обязательных полей нет, запрос возвращает ошибку.
- Если создать курьера с уже существующим логином, возвращается ошибка.

### **Логин курьера**

- Курьер может авторизоваться.
- Для авторизации нужно передать все обязательные поля.
- Если указаны неверные логин или пароль, возвращается ошибка.
- Если в запросе отсутствует одно из обязательных полей, возвращается ошибка.
- Если попытаться авторизоваться под несуществующим пользователем, возвращается ошибка.
- Успешный запрос возвращает `id` курьера.

### **Создание заказа**

- Можно указать один из цветов (`BLACK` или `GREY`).
- Можно указать оба цвета сразу.
- Можно создать заказ без указания цвета.
- Тело ответа содержит `track`.
- Используется параметризация для проверки различных комбинаций входных данных.

### **Список заказов**

- В ответе возвращается список заказов.
- Проверяется наличие необходимых ключей (`id`, `courierId`) в заказах.

## **Структура тестов**

Тесты организованы в соответствии с их функциональной принадлежностью:

📂 `tests/couriers/`

- `test_create_couriers.py` – тесты на создание курьера.
- `test_login_couriers.py` – тесты на логин курьера.

📂 `tests/orders/`

- `test_create_orders.py` – тесты на создание заказа (используется параметризация).
- `test_list_orders.py` – тесты на получение списка заказов.

## **Технологии**

- **Язык программирования:** Python
- **Библиотеки:** requests, pytest, allure-pytest
- **Стиль тестирования:** Автоматизированное API-тестирование
- **Отчётность:** Allure

## **Запуск тестов**

### 1. Установите зависимости:

```bash
pip install -r requirements.txt
```

### 2. Запустите тесты с формированием Allure-отчета:

```bash
pytest --alluredir=allure-results
```

### 3. Сгенерируйте и откройте отчет Allure:

```bash
allure serve allure-results
```
